# Context — ThePartFinder

Read this before touching the code. This folder is the source of truth for why the project looks
the way it does. If a doc and the code disagree, trust the code and fix the doc.

- `project-overview.md` — what this is, the phased scope, the proposal it came from.
- `architecture.md` — folder structure and layering rules for this Next.js app.
- `decisions.md` — ADRs: significant choices and why they were made.
- `conventions.md` — naming, styling, and code style conventions.
- `features/` — one file per feature (currently: `landing.md`).
- `changelog/development-log.md` — dated log of meaningful changes.

See also `/CLAUDE.md` at the repo root for the engineering rules every session must follow.
